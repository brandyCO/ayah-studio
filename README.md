# Ayah Studio

Create short vertical Quran videos (9:16) with a chosen reciter, rendered on your device.
Practice tools (Recite & Compare, flashcards) and ayah reminders are planned.

- Spec and roadmap: [CLAUDE.md](CLAUDE.md)
- Live test build: GitHub Pages (deployed automatically from `main`)

## Develop

```bash
npm install
npm run dev
```
