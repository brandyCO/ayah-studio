# Background credits

All four default backgrounds are original artwork generated procedurally for Ayah Studio by
`scripts/make-backgrounds.py` (numpy + Pillow + ffmpeg). No third-party footage or photos are used,
so there is no external license or attribution to track. Calm, abstract scenes only — no people,
faces, text or symbols.

| File | Kind | Source | License |
|---|---|---|---|
| `dusk-dunes.jpg` | Image, 1080×1920 | Generated (`scripts/make-backgrounds.py`) | Original work, same license as this repo |
| `night-sky.jpg` | Image, 1080×1920 | Generated | Original work |
| `mist-loop.mp4` | Video loop, 540×960, 12 s, H.264 | Generated (periodic motion → seamless loop) | Original work |
| `motes-loop.mp4` | Video loop, 540×960, 12 s, H.264 | Generated | Original work |
| `kid-moon.jpg` | Image, 1080×1920 — Moon garden (pastel night, moon, hills) | Generated (`scripts/make-kid-backgrounds.py`) | Original work |
| `kid-dunes.jpg` | Image, 1080×1920 — Desert dawn (pastel dunes, pale sun) | Generated (`scripts/make-kid-backgrounds.py`) | Original work |
| `kid-clouds-loop.mp4` | Video loop, 540×960, 12 s — Soft clouds | Generated (`scripts/make-kid-backgrounds.py`) | Original work |
| `*-loop.webm` | VP9 copies of the loops, used where H.264 can't be decoded | Derived from the files above | Original work |
| `*-thumb.jpg` | Picker thumbnails | Derived from the files above | Original work |
